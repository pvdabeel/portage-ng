# Graph assets

Stylesheets and fonts used by the portage-ng `--graph` HTML output.

## Stylesheets/

Stylesheets loaded by the generated HTML pages.

| File             | Installed as       | Purpose                                                                          |
|------------------|--------------------|----------------------------------------------------------------------------------|
| `portage-ng.css` | `.portage-ng.css`  | Unified stylesheet for all graph pages (deptree, gantt, detail, terminal, index)  |
| `proof.css`      | `.proof.css`       | Proof-tree page styles (used by print-aha scripts)                               |
| `index.css`      | `.index.css`       | Index page styles                                                                |

`--graph` also writes these site files into the repository graph directory
(`404.html`, `robots.txt`, `sitemap.xml` plus per-type sitemap shards)
for https://ebuild.portage-ng.ai. They are generated by
`sitefiles:write_site_files/2`, not copied from here.

`favicon.svg` is copied to the graph root from `Documentation/Images/icon.svg`
(the same mark as https://portage-ng.ai/assets/img/favicon.svg). Every
generated page links it, so the published origin serves the icon.

## Fonts/

Custom web fonts bundled for offline use by graph pages.

| File        | Installed as  | Purpose                         |
|-------------|---------------|----------------------------------|
| `meslo.ttf` | `.meslo.ttf`  | Meslo font for proof rendering   |
